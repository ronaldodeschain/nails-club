Noites para quem vive a música alternativa

O Nails Club é uma casa noturna fictícia com uma proposta acolhedora para pessoas ligadas à cena gótica e alternativa.

Conheça a agenda demonstrativa

Um espaço para descobrir e se conectar

A proposta reúne música, expressão artística e encontros em um ambiente de respeito. A identidade e a programação apresentadas nesta página são conceituais.

  • Curadoria de darkwave, gothic rock, industrial e EBM.
  • Encontros temáticos com espaço para diferentes expressões artísticas.
  • Dress code opcional: cada pessoa pode expressar seu próprio estilo.
O que significa dress code opcional?

É uma sugestão de estilo, não uma exigência. A pessoa pode escolher como se vestir.
